ダウンロードの前に。

DEM-Osc は本当に無料？

はい。体験版でも期限付きでもなく、ずっとあなたのものです。より深いエフェクトのいくつかは有料の Osc Collection 用に取ってあり、DEM-Osc はその無料の入り口です。

対応フォーマットと OS は？

2つのバージョンがあり、どちらも無料です。プラグインは macOS 用の VST3 と AU。Kontakt 版は Mac と Windows の無料 Kontakt Player で動き、メールでお送りするシリアルで Native Access に追加します。

中身は？

本物のハードウェアからサンプリングした5つのヴィンテージ・オシレーター、4つのコンボリューション・リバーブ空間、手作りのプリセット25種。グライド、ビブラート、モジュレーション・ホイールのルーティング付き。

ダウンロードして、プリセットを読み込んで、午後をまるごと溶かしてください。

残り4つのオシレーターが欲しくなったら、どこに来ればいいかはもうおわかりですね。
